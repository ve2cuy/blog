# Arduino PCR1000 project available

*Document converti depuis [ve2cuy.com/blog](https://ve2cuy.com/blog/index.php/2010/08/15/arduino-pcr1000-project-available/) — publié le 2010-08-15 — dernière modification : 2010-08-15*

---

I have decided to make the source code of my “Arduino- PRC1000” project available in its present form, as a ‘work in progress’.

It’s the same code that is use in the ‘youtube’ video so it should be working for you.

Beware that the program is available ‘As is’ with no guarantee at all.  No support is available.

If you choose to use this program to send commands to your PRC1000, you do so at your own risk.

There has been some discussion on the PCR1000 mailing list that you may be able to damage the PCR1000 by sending the wrong software commands to it.

Have fun …
